## 1.5.0

[Alterash Prime](https://ceterai.github.io/MyEnternia/Wiki/AlterashPrime) is here! Explore a new planet type added by this mode - like alterash, but colder, harder to traverse, with lots of layers and new biomes!  
The update also adds tier 5 and 6 armor sets, as well as loot items and set items! Loot items contain loot from corresponding chests, and set items contain full sets of armor of a specific type.

**Main:**

- added new planet type - [Alterash Prime](https://ceterai.github.io/MyEnternia/Wiki/AlterashPrime);
- added in total 48 objects, 5 items, 18 biomes;
- added in total 26 tree types, 1 bush type, over 100 recipes;
- updated [EDS Table](https://ceterai.github.io/MyEnternia/Wiki/EDSTable) (now [Alta Crafting Station](https://ceterai.github.io/MyEnternia/Wiki/AltaCraftingStation)) with new interface, new recipes and categories;
- added level 6 upgrade to [Alta Crafting Station](https://ceterai.github.io/MyEnternia/Wiki/AltaCraftingStation) with recipes for every mod object and more;
- added [Loot Box](https://ceterai.github.io/MyEnternia/Wiki/LootBox) items - when used they drop loot from certain (biome) chests from the mod;
- updated some ids (use the [Deprecation Station](https://ceterai.github.io/MyEnternia/Wiki/DeprecationStation) to convert deprecated items or get rewards for lost items).

**Alterash Prime:**

- added 1 atmosphere biome ([Eva Prime](https://ceterai.github.io/MyEnternia/Wiki/EvaPrime)) with clouds and bg stat effects;
- added 4 surface biomes ([Alterash Prime Gardens](https://ceterai.github.io/MyEnternia/Wiki/AlterashPrime-Gardens), [Alta Prime Labs](https://ceterai.github.io/MyEnternia/Wiki/AltaPrimeLabs), [EDS Grounds](https://ceterai.github.io/MyEnternia/Wiki/EDSGrounds), [Tavriya](https://ceterai.github.io/MyEnternia/Wiki/Tavriya));
- added 4 subsurface biomes ([Calocaves](https://ceterai.github.io/MyEnternia/Wiki/Calocaves), [Crystalline Prime](https://ceterai.github.io/MyEnternia/Wiki/CrystallinePrime), [Isoslime Plasts](https://ceterai.github.io/MyEnternia/Wiki/Isostratum), [Phospholion Mines](https://ceterai.github.io/MyEnternia/Wiki/PhospholionMines));
- added 2 shallow underground biomes ([Hidden Alta Labs](https://ceterai.github.io/MyEnternia/Wiki/HiddenAltaLabs), [Tonnova Grove](https://ceterai.github.io/MyEnternia/Wiki/TonnovaGrove));
- added 4 mid underground biomes ([Alta Lab Debris](https://ceterai.github.io/MyEnternia/Wiki/AltaLabDebris), [Bishyn Halls](https://ceterai.github.io/MyEnternia/Wiki/BishynHalls), [Hevika](https://ceterai.github.io/MyEnternia/Wiki/Hevika), [Shroomic Depths](https://ceterai.github.io/MyEnternia/Wiki/ShroomicDepths));
- added 2 deep underground biomes ([Hevika Tunnels](https://ceterai.github.io/MyEnternia/Wiki/HevikaTunnels), [Ionic Hive](https://ceterai.github.io/MyEnternia/Wiki/IonicHive));
- added 1 core biome ([Barren Ion Core](https://ceterai.github.io/MyEnternia/Wiki/BarrenIonCore));
- added 37 new natural objects that can be found on [alterash prime](https://ceterai.github.io/MyEnternia/Wiki/AlterashPrime) planets.

**Alterash:**

- updated planet descriptions;
- fixed a crash because of the [Snowy Alterash Ridges](https://ceterai.github.io/MyEnternia/Wiki/SnowyAlterashRidges) biome generation;
- rebalanced object spawns for some biomes.

**Alta:**

- added [EDS Halter](https://ceterai.github.io/MyEnternia/Wiki/EDSHalter)s - 5 different types of alta tank traps;
- added [EDS Status & Defensive Pod](https://ceterai.github.io/MyEnternia/Wiki/EDSStatusPod)s (WIP), [EDS Turret](https://ceterai.github.io/MyEnternia/Wiki/EDSTurret)s (WIP), [EDS Retainer](https://ceterai.github.io/MyEnternia/Wiki/EDSRetainer)s (WIP);
- added 2 other alta misc objects - [Alta Energy Source](https://ceterai.github.io/MyEnternia/Wiki/AltaEnergySource) and [Alta Drone Spawner](https://ceterai.github.io/MyEnternia/Wiki/AltaDroneSpawner) (WIP);
- added alta soda recipes to more original vending machines;
- added [Combat Set](https://ceterai.github.io/MyEnternia/Wiki/CombatSet) - lvl 5 alta armor set (WIP);
- added [Elite Set](https://ceterai.github.io/MyEnternia/Wiki/EliteSet) - lvl 6 alta armor set (WIP);
- added [Dreamer Set](https://ceterai.github.io/MyEnternia/Wiki/DreamerSet) - lvl 6 alta armor set (WIP);
- added 3 bonus helmets to already existing alta sets;
- added [VR Headset](https://ceterai.github.io/MyEnternia/Wiki/VRHeadset) - lvl 1 cosmetic hat;
- fixed some codexes.

**Other:**

- added palettes folder with palettes commonly used in the mod;
- updated coloring options for all armors & clothing;
- updated icons for some effects;
- updated biome chest loot tables;
- biome chest loot tables now can also drop their according loot boxes as bonus loot, meaning loot boxes can also drop themselves;
- minor bug fixes.
